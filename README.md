# Sanskrit Vedic Gurukul & Vedic Gurukul Trust Website
**"विद्या • संस्कार • सेवा" (Vidya • Sanskar • Seva)**

A production-grade, visually exceptional, traditional Sanskrit Vedic Gurukul and Vedic Gurukul Trust web application based on the educational philosophy and principles associated with Swami Dayanand Saraswati.

---

## 🌟 Key Features

1. **Bilingual Heritage Architecture (हिन्दी & English)**: Complete dual-language support with dynamic font pairing (`Noto Serif Devanagari`, `Yatra One`, `Cinzel`, `Plus Jakarta Sans`).
2. **Dual Heritage Themes**: Warm Parchment (Light) and Sandalwood Gold (Dark) themes with subtle Indian mandala geometry and gold foil styling.
3. **Interactive Vedic Shloka Audio Resonator**: Built-in 432Hz/528Hz Web Audio API synthesizer for sacred drone/resonance paired with verified verses (Gayatri, Shanti Path, Asato Ma, Sangathan Sukta).
4. **4-Step Admission Inquiry Wizard**: Multi-step student & guardian application workflow with validation and reference ID generation (`VG-ADM-2026-XXXX`).
5. **Vedic Gurukul Trust Donation Portal & 80G Receipt Generator**: Multi-tier contribution form with PAN collection, instant simulated payment, and printable 80G tax receipt modal.
6. **Interactive 360° Virtual Campus Map & Accessible Lightbox**: Visual architectural guide of the Gurukul grounds with keyboard-navigable photo gallery.
7. **Comprehensive Pages**:
   - **Home**: Hero, Heritage Introduction, Dayanand Philosophy Teaser, Academic Offerings, Trust Spotlight, Shloka of the Day.
   - **About Gurukul**: History, Vision, Dayanand Saraswati relationship, 4:30 AM - 9:30 PM Dinacharya, Faculty directory, FAQs.
   - **Philosophy**: In-depth Vidya-Sanskar-Seva triad, 6 Satyarth Prakash principles, Paninian linguistics, Shravana-Manana-Nididhyasana pedagogy.
   - **Education**: Course catalog (Prathama, Madhyama, Shastri, Acharya, Spoken Sanskrit, Youth Gurukul) with detailed syllabus modals.
   - **Admissions**: Step-by-step roadmap, eligibility checker, required documents, interactive wizard.
   - **Trust & Seva**: Bal Vidya Sahayata, Veda Samrakshan, Annakshetra, statutory banking placeholders, online donation portal.
   - **Campus & Gallery**: Category-filtered masonry grid, full-screen lightbox modal with keyboard navigation.
   - **Events & Notices**: Upcoming celebrations, RSVP modal, calendar export (`.ics`), live notice board.
   - **Contact**: Campus visiting guidelines, official info, inquiry form.
   - **Admin Desk**: Management portal (`#admin`) to review admissions, messages, donations, and publish notices.

## 🚀 Quick Start

```bash
# 1. Navigate to the frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build production bundle
npm run build
```
